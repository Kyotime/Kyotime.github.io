Privacy Policy — rclone-javier

rclone-javier is used only by its owner to access the owner's own Google Drive.

  • Data accessed: files in the owner's own Google Drive, only to copy them to and from the owner's own server.
  • No data is collected from, shared with, or sold to any third party.
  • OAuth tokens are stored only on the owner's private server and can be revoked at any time at Google Account permissions.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: via the GitHub profile of the owner.
